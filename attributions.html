Attributions & Credits

The shoulders we stand on.

Bibliomancy uses the following open-source resources and APIs:

Book Data Sources

  • Open Library (openlibrary.org) — Primary source for book covers, ISBNs, metadata, and descriptions (various open licenses)
  • Wikipedia (wikipedia.org) — Book descriptions, genres, and literary history, licensed under CC BY-SA 4.0
  • Google Books API — Limited fallback for book information (Google Terms of Service)
  • Bookshop.org — Book purchase links (affiliate partnership)
  • Bibliomancy Community Catalog — Aggregated reading statistics from our users

Trivia

  • Open Trivia Database (opentdb.com) — Trivia questions, licensed under CC BY-SA 4.0

Open Source Libraries

  • Jetpack Compose (Apache 2.0) — Android UI toolkit by Google
  • SwiftUI — iOS UI framework by Apple
  • Retrofit (Apache 2.0) — Type-safe HTTP client by Square
  • Coil (Apache 2.0) — Image loading library for Android
  • Room Database (Apache 2.0) — Local persistence by Google
  • Core Data — iOS local persistence by Apple
  • Ktor Client (Apache 2.0) — HTTP client framework by JetBrains
  • Supabase SDK (MIT) — Cloud database client by supabase-community
  • ML Kit Barcode Scanning (Apache 2.0) — Barcode detection by Google
  • CameraX (Apache 2.0) — Camera API by Google
  • Timber (Apache 2.0) — Logging library by Jake Wharton
  • Kotlin Serialization (Apache 2.0) — JSON serialization by JetBrains
  • WorkManager (Apache 2.0) — Background task scheduling by Google
  • Navigation Compose (Apache 2.0) — Navigation framework by Google
  • Gson (Apache 2.0) — JSON parsing library by Google
  • Kotlin Coroutines (Apache 2.0) — Asynchronous programming by JetBrains
